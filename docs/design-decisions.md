## 와이어프레임과 다르게 한 점

1. **수업 시간**: 와이어프레임 S1·S2는 "화·목 09:00–12:00 수업"인데, 데이터 세트(월·수 10–12, 화·목 13–15)를 따라요.
2. **S6-2 오늘 할 일**: 와이어프레임 목록이 데이터 세트 11/10 계획과 달라서 데이터 세트를 따라요.
3. **하위 주소**: S3-2, S5-1, S5-2에 각각 `/setup/upload/toc`, `/setup/review/resplit`, `/setup/review/compare` 주소를 줬어요. 뒤로 가기와 개발 확인이 쉬워요.
4. **S7 이해도 자기평가**: 데이터 세트에는 있지만 정의서 HM-02·03과 와이어프레임 S7에 없어서 넣지 않았어요.
5. **S4 '경계를 p.35로 옮기기' 버튼**: 페이지를 직접 고치는 기능으로 대신했어요. AI 경계 제안 형식이 나오면 추가해요.
6. **시안 없는 화면**: 캘린더 탭, 퀴즈 진입, 로딩·실패 상태는 제안안(지난 데모) 구성으로 만들어요.
7. **S8 퀴즈 진입**: 과목 카드 3개(잠김 · 풀 수 있음 · 다 풂)에서 고르고 `?subject=`로 문항 풀이에 들어가요. 운영체제·네트워크 문항은 목업에 없어서 MOCK 배지와 함께 '문항 준비 중'으로 막아 뒀어요.
8. **S8 퀴즈 문항**: 와이어프레임 7문항을 쓰고, 비어 있는 보기·정답·해설·근거 페이지는 채운 뒤 문항마다 MOCK 배지를 붙였어요 (11/7 결정 Q5 A).

## S9 책 쌓기 (11/7 결정 Q3 A)

- 과목별 책장 카드 3개를 한 화면에 세로로 놓고, 단원마다 가로로 눕힌 책 더미를 쌓아요 (참고 이미지 6·7)
- 책 1권 = 태스크 1개. 왼쪽 책등 띠 + 오른쪽 종이 결로 책 모양을 내고, 상태는 정의서 4-5 그대로 색 + 패턴 + 움직임 (`.blk`)
- 과목 색은 책장 제목과 단원 이름표에만. 책에는 쓰지 않아요
- 책 길이는 조금씩 다르게 (`BookBlock`의 `seed`) 해서 쌓인 느낌을 내요. 보충 학습 책에는 '보충' 글자
- 책을 누르면 오른쪽 '책 상세'에 상태·이해도 점수를 글로 보여줘요 (BK-05)
- 같은 책 컴포넌트를 홈 '최근 7일 쌓은 책'(요일별 더미)과 P1 책 박스에도 써요
- 화면 위 MOCK 배지: 목업 서버로 돌 때(`VITE_USE_MOCK`)는 헤더에 항상 표시해요
