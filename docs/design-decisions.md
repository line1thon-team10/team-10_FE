## 와이어프레임과 다르게 한 점

1. **수업 시간**: 와이어프레임 S1·S2는 "화·목 09:00–12:00 수업"인데, 데이터 세트(월·수 10–12, 화·목 13–15)를 따라요.
2. **S6-2 오늘 할 일**: 와이어프레임 목록이 데이터 세트 11/10 계획과 달라서 데이터 세트를 따라요.
3. **하위 주소**: S3-2, S5-1, S5-2에 각각 `/setup/upload/toc`, `/setup/review/resplit`, `/setup/review/compare` 주소를 줬어요. 뒤로 가기와 개발 확인이 쉬워요.
4. **S7 이해도 자기평가**: 데이터 세트에는 있지만 정의서 HM-02·03과 와이어프레임 S7에 없어서 넣지 않았어요.
5. **S4 '경계를 p.35로 옮기기' 버튼**: 페이지를 직접 고치는 기능으로 대신했어요. AI 경계 제안 형식이 나오면 추가해요.
6. **시안 없는 화면**: 캘린더 탭, 퀴즈 진입, 로딩·실패 상태는 제안안(지난 데모) 구성으로 만들어요.
