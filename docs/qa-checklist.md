## 일부러 낸 실패 응답 (콘솔 오류 아님)

/dev 'AI 상태 재현'에서 실패를 고르면 네트워크 탭에 아래 응답이 찍혀요. 화면이 처리하는 응답이라 JS 오류는 0건이에요.

| 응답                                                                                                                                        | 언제                                                            |
| ------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| `503 AI_FAILED` (`/api/plan/draft`, `/api/plan/resplit`, `/api/quiz/:id`, `/api/quiz/:id/submit`, `/api/tutor`, `/api/plan/replan/options`) | AI 상태 '실패'                                                  |
| 요청 시간 초과 (30초, `ECONNABORTED`)                                                                                                       | AI 상태 '느리게' (35초)                                         |
| 실패 단계 표시 (`/api/materials/jobs/:id`)                                                                                                  | S3 스캔본 분석 실패 (시나리오대로)                              |
| `404 NO_RESPLIT` (`GET /api/plan/resplit`)                                                                                                  | 다시 나누기 요청 없이 S5-2 주소로 바로 들어올 때 → 빈 화면 안내 |
| `404` 태스크 없음 (`POST /api/study/sessions`)                                                                                              | 다른 날 태스크 id로 집중 모드 주소를 열 때                      |

## 알아둘 점

1. `day9`의 `/study?task=t1`은 2.3초 안에 '책을 펼치는 중이에요'(여는 장면)만 보였어요. 기다리면 집중 모드로 넘어가요.
2. `overdue`(11/10)에서 `/study?task=t1`은 "태스크를 찾지 못했어요"가 나와요. t1은 11/9 태스크라 맞는 동작이에요. 시연은 홈 [시작]으로 들어가요.
3. `empty` 시드에서도 `/quiz`, `/study` 주소로 바로 들어가면 시드 데이터가 보여요. 시연 흐름(홈 → 버튼)에서는 안 보여요.
4. `day9`에서 `/quiz?subject=ds` 주소로 바로 들어가면 58%여도 문항이 보여요. 홈의 퀴즈 열림(70%)은 그대로예요.
5. 다시 나누기 평일 안은 데이터 세트 조건을 맞추느라 2주 합계가 20분 줄어요 (기획 확인).
