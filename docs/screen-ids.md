- `/dev`는 개발용 페이지예요. 시연 때는 헤더의 링크를 숨길 예정이에요.

## 화면 흐름

최초 1회: S1 → S2 → S3 (실패 시 S3-2) → S4 → S5 (다시 나누기: S5-1 → S5-2) → 홈

매일: S6 홈 → S7 기록 → P1-1 알림 (70% 달성·단원 완료·회복 때는 P1 박스) → S8 퀴즈 → S8-2 결과 → S9 책 쌓기 · S10 오답

자정·복구: 다음 날로 → 밀린 분량이 기준 미만이면 S6-2 이월, 이상이면 P2 분배안 → 적용 → P1 회복 박스
