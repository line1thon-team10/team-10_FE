## 화면 흐름

최초 1회: S1 → S2 → S3 (실패 시 S3-2) → S4 → S5 (다시 나누기: S5-1 → S5-2) → 홈

매일: S6 홈 → [시작] S12 집중 모드 → S12-1 공부 끝 → S7 기록 → P1-1 알림 (하루 마무리·단원 완료·회복 때는 P1 박스) → S8-1 퀴즈 고르기 → S8 퀴즈 (서술형 S8-3) → P3 퀴즈 후 책 쌓기 → S8-2 결과 → S9 책 쌓기 · S10 오답

자정·복구: 다음 날로 → 밀린 분량이 기준 미만이면 S6-2 이월, 이상이면 P2 분배안 → 적용 → P1 회복 박스. 속도가 예상과 다르면 홈 접속 때 P4

계획 바꾸기: S6 [+ 계획 추가] → S13 · [과목·계획 관리] → S14 · S11 일정 삭제 → P5 · 말로 일정 추가 → S6-4
