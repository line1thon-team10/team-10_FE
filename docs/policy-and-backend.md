# 정책 값 · 확정 필요 항목

## 정책 값 (`src/config/app.js`)

판정·계산은 서버가 하고, 프론트는 안내 문구에만 써요. 출처는 정의서 4장이고, 8장에 "확인 필요"로 남은 항목이 섞여 있어요.

| 값         | 내용                                                        |
| ---------- | ----------------------------------------------------------- |
| 70%        | 오늘 계획 페이지의 70%를 기록하면 퀴즈가 열림 (4-4)         |
| 85점       | 서술형 정답 기준 (4-1)                                      |
| 50%        | 밀린 페이지가 하루 평균 계획의 50% 이상이면 분배안 (4-8)    |
| 80 / 50    | 안정 80~99 · 흔들림 50~79 · 붕괴 위기 50 미만 (4-2)         |
| 15~60분    | 태스크 길이 (PL-02)                                         |
| 8초 / 30초 | AI 대기 화면: 8초 지나면 안내, 30초 지나면 다시 시도 [임시] |
